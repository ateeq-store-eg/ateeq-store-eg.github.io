1. Connect (one time on this device)

Saving needs a GitHub access token. It is stored only in this browser and goes only to GitHub. Create one at github.com/settings/personal-access-tokens/new: pick this repository only, and set Repository permissions, Contents: Read and write. Paste it here and tap Connect. Anyone opening this page without the token can look but cannot change anything.
